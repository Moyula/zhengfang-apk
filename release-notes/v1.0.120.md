# 1.0.120 高德地图、搜索认证与免费额度控制

## notes

- 签到选点接入高德原生地图，支持点选、缩放和坐标自动换算；地点搜索统一走云端，保留基础地图、系统定位和手动坐标入口。
- 修复“T1 航站楼”与“1号航站楼”等名称差异导致的搜索遗漏，核对城市、航站楼和国内到达等信息，相近地点明确提示后由用户选择。
- 高德配置通过云端认证和加密下发，增加临时密钥、有效期、防重放与限流；Web 服务 Key 保留在云端，正式包不内置高德 Key。
- 地图管理端增加免费用量控制，单 Key 与账号共享总池同时限额；先计数再请求，失败也计数，额度耗尽或权益到期立即停用，轮询不能叠加账号额度。
- 插件站开放地图 Web Key 捐赠入口，支持加密提交、人工审核和自行撤回；相同高德账号共享免费额度，重提不重置计数。
- 原生选点与插件后台搜索由宿主签名认证，移除客户端直接调用高德 POI 的路径；旧版本保留开源搜索。
- 高德 SDK 在用户同意隐私说明后初始化，地图随页面前后台暂停和恢复，关闭页面后释放资源。
- 与 SDK 3.6.0 / API 3 保持兼容，同步地图接入、密钥配置与安全边界文档。普通更新不强制安装。
