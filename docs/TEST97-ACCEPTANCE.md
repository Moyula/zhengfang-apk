# 1.0.97 测试版修复与验收

## 已实现

- 成绩学期仅对 `studyOptions.gradeTermFormat=academic-year-semester` 的提供者启用本地补全。八月切换学年，提供当前及前七学年的已到来常用学期；学校名称与查询 ID 优先，未来学年通常隐藏，确实返回过成绩的学期保留。补全不改变课表当前学期。用户选择、缓存和学校列表刷新错误分别保留。
- 共用选择器的绝对行号渐入改为首屏相对序号和有界延迟；动画结束后所有可用行完全可见，滚动新行不等待计时。两行名称和大字体使用实际行高。玻璃背景、形变和折射参数保持。
- 成绩页收起的选择栏恢复原先单行、常规字体下 50 dp 的紧凑高度，按用户补充，未展开的胶囊最大宽度收为280dp，窄窗口受可用宽度限制；展开时沿原动效过渡到内容区宽度，菜单保留两行名称。内置学期监听日期、时间、时区变化，并在返回前台时检查日期，八月及二月自动补充到来的学期。已有有效选择不会因本地日期改变而跳转，不为补全主动刷新学校接口。
- 新正方公共协议锁定库 3.2.4 增加可选只读 `selection.filters`。网页未开放时禁用筛选；开放时结合静态选项及网页开关对应的动态来源，多选、应用、清空均使用学校查询参数。输入按账号、提供者、轮次、筛选定义与十五分钟有效期校验；普通页面令牌变化不使授权或筛选失效。旧版本库保留原样。
- 设置首页恢复“退出预览 / 退出登录”，真实退出确认一次，预览直接结束且保留真实账号与缓存；清空任务栈防止返回旧预览。账号子页不重复提供退出。
- SDK 3.2.7 / API 3，同步契约、App 资源、模板和网站文档。新声明与方法最低 code 97，旧六项选课能力组继续有效，87/96 客户端拒绝新包。现有凭证、确认及防重放边界未放宽。

## 本地证据

- `test97-capsule-width`：按用户澄清后的胶囊横向宽度追加 12 项回归通过，覆盖收起280dp/展开原内容区宽度、反复开关、窄窗口约束、长列表末项及玻璃开关下文字像素。曾启动的日期/高度补充构建因这一澄清主动取消，最终 APK 以交付报告记录的后续构建为准。
- `test97-date-compact-final`：24 项通过，包括 Android 7/12L 日期、时间、时区与前台恢复事件、关闭后监听释放、学期政策、恢复原尺寸及长列表文字。首次日期测试因 Robolectric 未自动授予清单中已声明的内部广播权限而失败；补齐测试安装环境后全数通过，未放宽生产权限。
- `test97-ui-final`：49 项 JVM 通过，包含学期政策、共用动画、实际原生 Canvas 文字像素、长列表、两行大字体、预览/真实退出入口与多选筛选界面，以及既有顶栏回归。
- `test97-contract-final`：另 21 项 JVM 通过，覆盖打包清单、六类预装包、旧能力组、宿主边界、学校绑定及站点授权运行链。
- 最终独立解压开发套件 223 项 JS/QuickJS 通过，独立 SDK 重建与类型检查通过；网站 62 项 Worker/SQL 通过，网站构建与 dry-run 通过。最终摘要保存于交付报告。历史失败日志保留，不把失败任务中的旧 XML 当作本次通过结果。
- 第一轮测试 CI 841 项 JVM 无失败（837 通过、4 项可选真实账号跳过），lint 发现七处日期 API 26 兼容错误；已改用 Android 7 可用的 Calendar，`test97-api24` 九项学期回归通过。后续 CI 结果单独记录，不把失败流水线算作成功交付。
- 本轮用户明确授权网站部署、两个仓库提交推送，以及仅测试包 CI；Gitee 必须跳过。线上版本与 CI 结果以交付报告为准，不创建正式 tag、稳定 Release 或更新 main。
